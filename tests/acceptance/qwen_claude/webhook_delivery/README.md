# Signed webhook delivery task

Implement `verify_webhook` in `webhook.py` and `DeliveryStore` in `delivery_store.py` using only the Python standard library. Edit those two source files only. Run `python -m unittest -q` before and after editing.

`verify_webhook(body, signature, timestamp, secret, now, max_age_seconds=300)` verifies a provider request and returns its parsed JSON object. `body` and `secret` must be nonempty `bytes`. `timestamp` must be an unsigned ASCII decimal string with no whitespace. `now` and `max_age_seconds` must be integers, excluding booleans; the age limit must be positive. Reject future timestamps and ages greater than the limit, while accepting a timestamp exactly at the limit. The signature header must be exactly `sha256=` followed by 64 hexadecimal characters, with no surrounding whitespace. Compare a SHA-256 HMAC of `timestamp.encode("ascii") + b"." + body` against the header using a constant-time digest comparison. Verify the raw body bytes before decoding or parsing them.

After verification, decode strict UTF-8 JSON. The top level must be an object with `delivery_id` and `resource_id` as nonempty strings without surrounding whitespace, `event_type` equal to `created`, `updated`, or `deleted`, and `revision` as a nonnegative integer excluding booleans. Preserve any additional JSON fields. Reject duplicate keys at any object level and nonfinite JSON numbers. Every invalid input raises `WebhookError`, without leaking the secret or digest in its text.

`DeliveryStore(db_path)` is a process-safe SQLite replay ledger. `record(event)` atomically inserts a verified event, returning `True` on its first delivery and `False` on an identical replay. The same `delivery_id` with a changed field raises `WebhookError`. Dictionary key order does not make an event different. Separate `DeliveryStore` instances using the same path, including concurrent callers, must agree on one outcome. `get(delivery_id)` returns a fresh event dictionary or `None`, and `count()` returns the number of distinct accepted deliveries. These methods must not mutate caller dictionaries. Initialization may create its table; records must survive a new store instance. Invalid event dictionaries passed directly to `record` raise `WebhookError`.
