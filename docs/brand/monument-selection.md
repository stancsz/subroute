# Owner-selected Monument A

On 2026-10-11 the owner rejected the previous Mesa B, explored landscape,
monogram and typographic alternatives, and chose the corporate option A:
“Go with A, simple and symmetrical.” The production mark follows that choice.

The canonical 32×32 SVG contains a flat 28×7 cap and a centered tapered pillar.
Its geometry mirrors around x16, with a 2px gap between the two pieces. Current
wordmarks, fonts, logo boxes and navigation layout are retained. The same
vector replaces inline marks and encoded favicons in Subroute, Desktop
connection, the company home/enquiry/docs/404 and gateway console/sign-in.

Image-backed GPT-6.1 Sol direction corrected pillar proportions to match the
chosen concept. Final native 16/20/24/32px specimens in both polarities and
actual desktop/phone placements passed its bounded visual inspection.
[Independent nonauthor review](monument-review.md) passed exact geometry,
source parity, placement, small-size and publication-artifact checks.

Published company Worker version: `85e80b22-aa46-4289-9e2b-52282f09ae4d`.
Published console Worker version: `471c7efa-cefb-4f4a-91ce-1edb0cf7a898`.
The company release changes exactly six assets over the verified live baseline:
four HTML files and the canonical mark/favicon. Its sole Worker module,
authentication code and bindings remain byte-identical. Public asset readback
matches reviewed bytes; independent checks confirmed owner admin 401,
console 302 to sign-in and all public sign-in assets. No routing or policy changes.
Production/local staging policies retain MiniMax/Luna and versions 98/627.

Only this logo replacement and its documentation are committed. Preexisting
business/admin/router edits remain preserved in their working trees. Historical
redesign and concept proofs describe their original versions; this record and
current canonical SVG describe the selected identity. No trademark/legal
uniqueness assertion is made.
