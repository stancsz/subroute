# Badlands Monument mark

The owner selected corporate option A: “Go with A, simple and symmetrical.”
The canonical `badlands-mark.svg` is a monochrome, two-piece abstraction of a
Drumheller hoodoo: a flat cap and a centered tapered pillar. It replaces the
previous stepped Mesa B. Earlier concept and redesign proofs remain historical.

Preserve the 32×32 view box and mirror symmetry around x16. The cap is x2/y3,
28×7 with radius 1.2; the pillar begins at y12 and ends at y28. Its straight
slopes and small corner curves are mirrored. Keep the 2px gap clear; do not
stretch, rotate, add a wave, enclose the symbol or add extra geological detail.

Use currentColor for black-on-white or white-on-black application. Keep the
company/product name as selectable text alongside it. Headers use 30–32px,
compact navigation 24px and footers 20px. The favicon uses the same geometry
on a white square backing for contrast against dark browser tabs.

The exact same vector is packaged in the company site and inlined in Subroute,
Desktop connection, gateway console and sign-in. Native 16/20/24/32px specimens,
full lockups and mobile placement were reviewed separately from concept images.
Generated comparison boards are design references; production uses this SVG.
